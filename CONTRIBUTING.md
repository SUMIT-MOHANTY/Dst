# Contribution Guidelines

## Code of Conduct
Be respectful and constructive.

## Setting Up
Fork the repo and clone locally. Install dev requirements: \`pip install -r requirements-dev.txt\`

## Development
- Branch naming: \`feature/ticket-description\`
- Run linting: \`flake8 .\`
- Run tests: \`pytest\`

## Pull Requests
1. Update CHANGELOG.md
2. Ensure CI passes
3. Request review from maintainers
