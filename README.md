# Contact Form with JavaScript Validation

A professional contact form with real-time validation and immediate user feedback.

## Features

- **Real-time validation**: Validates input as user types
- **Visual feedback**: Color-coded borders for valid/invalid states
- **Error messages**: Clear, descriptive error messages for each field
- **Character counter**: Live character count for message field
- **Form validation**: Prevents submission with invalid data
- **Success state**: Animated success message after submission
- **Reset functionality**: Option to send another message

## Validation Rules

| Field | Requirements |
|-------|--------------|
| Name | Minimum 2 characters, letters only |
| Email | Valid email format |
| Phone | Valid format (optional) |
| Subject | Must select an option |
| Message | 10-500 characters |

## Usage

Simply open `index.html` in a web browser. No server required.

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and animations
- `validation.js` - Form validation logic
