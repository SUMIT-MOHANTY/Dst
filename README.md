# Admin Panel for Nitesh

A simple Flask-based admin panel to manage bio and projects dynamically.

## Features
- Create, Read, Update, Delete bio information
- Create, Read, Delete projects
- No code changes needed for content updates

## How to Run
1. Install dependencies: pip install -r requirements.txt
2. Run the app: python app.py
3. Visit http://localhost:5000
4. Admin panel at http://localhost:5000/admin

## Files
- app.py: Main Flask application
- templates/: HTML templates
- data.json: Auto-generated data storage
