# Nitesh Saw Portfolio

A Flask-based portfolio website showcasing profile, skills, and projects.

## Setup

1. Install dependencies:
   pip install -r requirements.txt

2. Initialize the database and seed data:
   python seed_db.py

3. Run the application:
   python app.py

4. Visit http://127.0.0.1:5000

## Database Seeding

The seed script populates the database with:
- Nitesh Saw\'s profile information
- Technical skills with proficiency levels
- Sample projects with descriptions and links
