# Animated Portfolio with Admin Dashboard

## Features
- Smooth CSS animations (fade-in, slide-up, pulse, hover effects)
- Contact form with AJAX submission
- Admin dashboard with message management
- Responsive design

## Setup
pip install -r requirements.txt
python app.py

## Access
- Homepage: http://localhost:5000
- Admin Dashboard: http://localhost:5000/admin
- Default Admin Password: admin123

## Testing
1. Submit a message via the contact form
2.Navigate to Admin and login with 'admin123'
3. View and manage received messages
